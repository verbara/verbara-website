# Website Redesign — Phase E: Brand assets, OG image, sitemap, meta polish

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the redesign with the remaining brand-asset deliverables — refined V-mark SVG (3 lockups), favicon set (SVG + ICO + PNG sizes), one universal OG image, sitemap.xml integration, robots.txt, and the meta polish (Twitter card, apple-touch-icon, og:image link) — plus close the Phase D-leftover Card primitive `data-*` forwarding gap.

**Architecture:** All brand SVGs are hand-authored under `public/brand/` and committed (text-based, deterministic, scalable). PNG/ICO derivatives are generated by Node scripts (`scripts/generate-icons.mjs`, `scripts/generate-og.mjs`) using `sharp` (SVG → PNG) and `png-to-ico` (PNG → ICO). Scripts run on demand (`npm run brand:icons`, `npm run brand:og`); outputs are committed to git so Cloudflare Workers Builds doesn't need native binaries. Sitemap is generated at build time by `@astrojs/sitemap` (declarative integration). Layout.astro adds the missing meta tags. Card primitive gets a final cleanup to forward arbitrary HTML attributes.

**Tech Stack:** Astro 6.3, Tailwind v4, `sharp` for SVG→PNG, `png-to-ico` for ICO, `@astrojs/sitemap` for sitemap. No new client-side deps.

**Spec:** `docs/specs/2026-05-09-website-redesign.md` §4 (brand identity), §5 (logo + brand assets), §10 Phase E.

**Phase D baseline:** branch `redesign/phase-e-assets` started from `main` at commit `6a7e780 Merge pull request #6 from verbara/redesign/phase-d-dev-legal`. Worktree at `.worktrees/redesign-phase-e`. Tests green: 144/144 e2e, Lighthouse 6/6.

**What Phase E explicitly does NOT do:**
- Real legal copy (placeholder remains until lawyer drafts).
- Sticky table-of-contents on legal pages (deferred).
- Reduced-motion guards on chevron rotations (low priority).
- Fonts beyond Geist Sans/Mono (already self-hosted in Phase A).
- Per-locale OG images (1 universal English version per user direction).
- Schema.org / JSON-LD structured data (separate SEO task).

End state: `verbara.io` ships with proper brand identity assets, a real sitemap.xml + robots.txt, Twitter/social cards rendering correctly, and a finalized Card primitive. Phase E is the closing phase of the redesign.

## Conventions

- **Brand SVGs are source-of-truth, committed.** PNG/ICO derivatives are generated by scripts. The scripts run on-demand locally (developer), outputs are committed. Cloudflare just serves the static files.
- **Sharp is a devDependency only.** Cloudflare Workers Builds doesn't need it because PNGs are pre-generated.
- **Favicon strategy:** modern browsers prefer `favicon.svg`. Older browsers + iOS get the PNG fallbacks. Keep `favicon.ico` as the universal compatibility fallback (legacy IE, default-to-root expectation).
- **Commit cadence:** commit per task. Conventional Commits (`feat:`, `fix:`, `chore:`, `test:`, `docs:`, `refactor:`). No `Co-Authored-By`.

## Task 3: Favicon generator script + run it

**Files:** `scripts/generate-icons.mjs` (new), `public/favicon.ico` (new), `public/apple-touch-icon.png` (new), `public/icon-192.png` (new), `public/icon-512.png` (new).

### Step 3.1: Create `scripts/generate-icons.mjs`

```javascript
#!/usr/bin/env node
/**
 * Generates favicon + apple-touch-icon + PWA icons from
 * `public/favicon.svg` (the source-of-truth ink-background V-mark).
 *
 * Run: npm run brand:icons
 *
 * Outputs (overwrites if present):
 *   public/favicon.ico          16x16 + 32x32 multi-size
 *   public/apple-touch-icon.png 180x180 (iOS home screen)
 *   public/icon-192.png         192x192 (PWA standard)
 *   public/icon-512.png         512x512 (PWA standard, splash)
 */

import { readFile, writeFile } from 'node:fs/promises';
import { resolve, dirname } from 'node:path';
import { fileURLToPath } from 'node:url';
import sharp from 'sharp';
import pngToIco from 'png-to-ico';

const __dirname = dirname(fileURLToPath(import.meta.url));
const root = resolve(__dirname, '..');

const sourceSvg = resolve(root, 'public/favicon.svg');
const outICO = resolve(root, 'public/favicon.ico');
const outApple = resolve(root, 'public/apple-touch-icon.png');
const out192 = resolve(root, 'public/icon-192.png');
const out512 = resolve(root, 'public/icon-512.png');

async function main() {
  const svg = await readFile(sourceSvg);

  // 16x16 + 32x32 PNGs as ICO inputs (kept in memory only)
  const png16 = await sharp(svg).resize(16, 16).png().toBuffer();
  const png32 = await sharp(svg).resize(32, 32).png().toBuffer();
  const ico = await pngToIco([png16, png32]);
  await writeFile(outICO, ico);
  console.log(`✓ ${outICO}`);

  // 180x180 apple-touch-icon
  await sharp(svg).resize(180, 180).png().toFile(outApple);
  console.log(`✓ ${outApple}`);

  // 192x192 + 512x512 PWA icons
  await sharp(svg).resize(192, 192).png().toFile(out192);
  console.log(`✓ ${out192}`);

  await sharp(svg).resize(512, 512).png().toFile(out512);
  console.log(`✓ ${out512}`);
}

main().catch((err) => {
  console.error('generate-icons failed:', err);
  process.exit(1);
});
```

### Step 4.2: Create `scripts/generate-og.mjs`

```javascript
#!/usr/bin/env node
/**
 * Generates the universal OG image PNG from public/og/_template.svg.
 * Run: npm run brand:og
 *
 * Output: public/og/og-default.png (1200×630)
 *
 * Note: SVG <text> rendering quality depends on whether the named fonts
 * are installed on the build machine. Geist Sans falls back to system
 * sans-serif if not present. For consistent output across environments,
 * install Geist Sans system-wide OR commit the rendered PNG (this script's
 * approach: commit the PNG, regenerate when source changes).
 */

import { resolve, dirname } from 'node:path';
import { fileURLToPath } from 'node:url';
import sharp from 'sharp';

const __dirname = dirname(fileURLToPath(import.meta.url));
const root = resolve(__dirname, '..');

const sourceSvg = resolve(root, 'public/og/_template.svg');
const outPng = resolve(root, 'public/og/og-default.png');

async function main() {
  await sharp(sourceSvg, { density: 300 })
    .resize(1200, 630)
    .png({ compressionLevel: 9 })
    .toFile(outPng);
  console.log(`✓ ${outPng}`);
}

main().catch((err) => {
  console.error('generate-og failed:', err);
  process.exit(1);
});
```
